# UK Rail / Ticket BI – Final Project (Power BI)

Final Power BI project for the **Data Analysis & Business Intelligence Diploma** at **IMP**, focused on UK rail / ticket analytics.

## Overview

This report explores rail ticket purchase and journey data across multiple Power BI pages:

- Ticket Purchase Trends
- Pricing Insights
- Passenger Behavior
- Journey Performance
- Refund & Compensation
- Ticket Type Utilization
- Arrival Time Analysis
- Railcard Impact
- Station Details
- Insights

Included file:

- `Final_Project.pbix` — Power BI report

## Tools

- Microsoft Power BI Desktop

## How to open

1. Clone or download this repository.
2. Open `Final_Project.pbix` in **Power BI Desktop**.
3. Refresh the data model if prompted (requires the original data sources configured in the report).
